# 株式会社サンエス 仮サイト

業務用エアコンの販売・施工を行う株式会社サンエスの、確認用の仮サイトです。
HTML／CSS／JavaScript だけで作った静的サイトで、ビルドは不要です。

## 確認方法

`index.html` をブラウザで開けば表示できます。
施工事例はJavaScriptで表示しているため、次のようにローカルサーバーで開くと確実です。

```sh
cd sanes-site
python3 -m http.server 8000
# → http://localhost:8000/
```

## よくある更新

### 施工事例を追加する
`assets/js/works-data.js` の配列に、既存の1件をコピーして追加し、`id` を重複しない値にします。
`featured: true` にすると、トップページに表示されます（最大4件）。
本番の事例では `tmp: false` にすると【仮】ラベルが消えます。

### 電話番号・LINEのURLなどを差し替える
ヘッダー・フッター・固定ボタンは、各HTMLファイルに同じ内容が書かれています。
次の文字列を、すべてのファイルで一括置換してください。

| 項目 | 仮の値 |
|---|---|
| 電話番号（表示） | `0120-000-000` |
| 電話番号（リンク） | `tel:0120000000` |
| LINE URL | `https://lin.ee/XXXXXXX` |
| 所在地 | `〒000-0000`、`東京都〇〇区〇〇 0-0-0 〇〇ビル 0階` |
| 受付時間 | `9:00〜18:00（日曜・祝日休み）` |
| サイトのURL | `https://www.example.com/` |

構造化データ（各HTMLの `<script type="application/ld+json">`）の電話番号・住所・営業時間・対応エリアも、あわせて差し替えてください。

### 写真を差し替える
画像はすべてプレースホルダーです。各 `<img>` の直前のコメントと `alt` に、必要な写真の内容を書いています。
同じファイル名の JPEG／WebP を用意し、`src` の拡張子を変えて差し替えてください（縦横比 3:2、横1200px程度を推奨）。
メーカーのロゴが写り込んだ写真や、他社の画像は使わないでください。

## 本番公開前にやること

- 各HTMLの `<meta name="robots" content="noindex, nofollow">` を削除する（仮サイトは検索エンジンに登録しない設定）
- 上部の「確認用の仮サイトです」の帯（`.draft-bar`）を削除する
- `canonical` と構造化データのURLを本番ドメインにする
- `og:image` 用のPNG画像（1200×630）を用意して追加する
- お問い合わせフォームの送信先を設定する（現在は送信されず、完了表示が出るだけ）
- 正式なプライバシーポリシーに差し替える
- LINE公式アカウントのボタン・アイコンを使う場合は、LINEのガイドラインに従う（現在はLINEのロゴを使っていません）
